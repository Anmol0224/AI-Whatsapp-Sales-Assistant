# Frontend

React + TypeScript application built with Vite and styled with Tailwind CSS v4.

## Commands

- `npm run dev` — start the development server.
- `npm run typecheck` — check the generated TypeScript project configuration.
- `npm run build` — type-check and create the production build.
- `npm run preview` — preview the production build locally.

The current screen is a temporary foundation verification page, not the final dashboard.
